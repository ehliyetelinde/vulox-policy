1. Zero Personal Data Collection Policy

Vulox IPTV Player is designed with a privacy-first approach:

  • No Data Transmission: Your playlists, stream links, and channel preferences are never sent to any external server.
  • Local Storage Only: All configuration data is saved exclusively on your local device.
  • No User Account: No registration, email, or personal credentials are required to use the app.

2. Required App Permissions

Only essential Android permissions required for media playback are requested:

  • INTERNET: Required to establish network connections with user-defined media streams.
  • WAKE_LOCK: Keeps screen active during continuous video playback.
  • STORAGE: Used only if the user explicitly opens a local M3U file from device memory.

3. Children's Privacy

We do not knowingly collect personal information from children under 13.
